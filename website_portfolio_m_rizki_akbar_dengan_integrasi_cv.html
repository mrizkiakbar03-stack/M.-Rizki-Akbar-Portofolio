Tugas Akhir / Skripsi S1 Matematika

Analisis & Pemilihan Model Estimasi Ketepatan Waktu Kelulusan Mahasiswa (13.000+ Record Data)

Latar Belakang & Tujuan

Ketepatan waktu kelulusan merupakan indikator efisiensi akademik perguruan tinggi. Penelitian ini menganalisis 13.000+ data rekam akademik mahasiswa untuk mengevaluasi akurasi model statistik dan Machine Learning.

Metodologi & Algoritma

  • Regresi Logistik: Pemodelan probabilitas biner berdasarkan odds ratio variabel prediktor.
  • Decision Tree Classification: Pemisahan node berbasis Information Gain / Gini Impurity untuk mengidentifikasi aturan keputusan kuantitatif.
  • Tools Digunakan: Python, Minitab, RapidMiner, MS Excel.

Evaluasi Model & Hasil

Evaluasi komprehensif dilakukan menggunakan Confusion Matrix, Akurasi, Presisi, Sensitivitas, Spesifisitas, dan Kurva ROC. Hasil memberikan rule-based intuitif bagi pihak program studi dalam merancang Early Warning System ketepatan kelulusan.

Laporan Kerja Praktik • PT Jasa Raharja Riau

Analisis Pendapatan Samsat & Tingkat Kerentanan Kecelakaan Lalu Lintas

Tanggung Jawab & Ringkasan Studi

Bertanggung jawab merekap data pendapatan Samsat, verifikasi dokumen administratif, serta mengolah data historis klaim kecelakaan lalu lintas PT Jasa Raharja Cabang Riau.

Penanganan Overdispersi

Data cacah (count data) kecelakaan diuji menggunakan Regresi Poisson dan dilanjutkan ke Regresi Negatif Binomial untuk mengatasi masalah overdispersi varians sehingga diperoleh estimasi parameter yang akurat.

Rekomendasi Kebijakan

Menghasilkan grafik komparasi data aktual vs prediksi serta peta kerentanan kelompok usia produktif sebagai bahan pertimbangan strategis sosialisasi keselamatan berkendara.
